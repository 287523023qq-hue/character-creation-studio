# 场景图派生（环境＋角色＋动作）

场景图是**成品图**，不是生产资产：把已锁定的角色放进一个具体环境、做一个具体动作，生成单张有氛围的图（发布、展示、封面用）。它与定妆照分工不同——定妆照锁角色，场景图用角色；**场景图不能替代母版/定妆照作锚点**，也不能反过来当锁定依据。

## 前置条件

- 角色必须已有**定版锚点**（步骤 ⑦ 锁定记录＋母版或定妆照）：场景图一律挂锚点图作参考图生成，角色外观以锚点为准。
- 没有锁定记录的探索候选也可以出场景图，但只能算一次性探索图，不保证还是"同一个角色"，不得称派生。

## 抽法：环境与动作默认随机，指定优先

用户明确指定了环境、动作或服装时，以指定为准、跳过对应抽取；未指定的一律随机抽，**随机数决定，执行者不许凭感觉挑**。抽完必须报抽（抽到的环境与动作各是什么）。

顺序：**先抽环境，再抽动作**，各自两级抽（先等概率抽类别，再类内等概率抽条目）。

### 环境池（26 条，只收自带氛围、出片的环境）

| 类别 | 条目 |
|---|---|
| 城市生活（7） | 雨夜夜市街头、霓虹灯小巷、屋顶天台黄昏、老城石板路、深夜便利店门口、樱花季电车站台、江边码头 |
| 自然野外（7） | 海边灯塔下、雪山木屋前、竹林小径、湖畔芦苇荡、云海山顶、秋日枫树林、星空下的草原 |
| 室内空间（6） | 老茶馆窗边、旧图书馆高窗旁、温室花房、复古咖啡馆、阁楼天窗下、画室 |
| 奇幻异境（6） | 漂浮岛屿边缘、水晶洞穴、巨树树冠平台、云端集市、月光下的古代遗迹、深海玻璃穹顶 |

### 动作池（38 条，只收一个瞬间能定格的简单动作）

| 类别 | 条目 |
|---|---|
| 姿态类（10） | 缓步前行、倚栏远望、坐在台阶上休憩、蹲下观察近处某物、伸手触碰近旁物件、仰头望天、回眸看向镜头、迎风站立衣角被风吹起、拾级而上、坐在高处双腿自然垂落 |
| 态度类（10） | 双手插兜斜视镜头、单手插兜回头、双臂抱胸而立、单手托腮沉思、抬手扶住头部配饰、指间轻转一朵花、叼着一枝花、嘴角叼着一片草叶、闭目聆听、侧头挑眉轻笑 |
| 生活道具类（10） | 指间夹烟轻吐烟雾、举杯小酌、双手捧着热茶杯、怀抱一只猫、撑伞而立、提灯而行、坐在窗边翻书、轻摇折扇、怀抱一束花、肩扛一件长物（伞/杖/鱼竿） |
| 环境互动类（8） | 伸手接雨〔需雨/雪环境〕、指尖轻碰花枝、单手按在老树干上、俯身看水面倒影〔需水边环境〕、踩过浅水洼〔需雨后或水边环境〕、推开一扇木门、扶着灯柱回望、靠在石柱旁 |

规则：
- **一次只做一个动作**：连续动作（打斗、跳舞、奔跑、多段表演）不入池、不得临时添加——静态图承载不了，必崩。
- 动作条目带〔需…环境〕的，与抽到的环境不兼容时**只重抽动作**（保先抽的环境），上限 3 次，与本包其他重抽规则一致。
- 同一角色同一批场景图，动作不得重复（无放回）。

## 服装与特征

- **锁脸不锁衣**：服装可按环境调整（雪山换冬装、海边换夏装），在提示词中一句写明；角色的标志性特征（对照锁定记录：脸、发型、核心识别点、标志性配饰/纹样）必须保留。
- 风格以角色锁定的 Style 行**原文**为准，不得改写；有世界观锁定的，环境不得与世界层禁用元素冲突。

## 提示词结构（模板）

```
把参考图中的角色放进一个真实场景里，生成一张单张场景插画：
环境：<环境句>。
动作：<动作句，一个瞬间的简单动作>。
服装：<按环境调整时写明，否则写"与参考图一致">。
角色外观以参考图为准，标志性特征保留。
Style: <Style 行原文>
竖构图（默认 3:4），角色全身或大半身入画、是画面主体。
单张场景插画，不要双视图、不要设定图版式、不要文字、不要水印。
```

## 验收（三条，单独一套）

1. **角色可辨**：对照锁定记录逐项核对标志性特征，丢了核心识别点即打回。
2. **风格命中**：对照 Style 行逐词核对，环境再好看、风格跑了也算不通过。
3. **动作与道具不崩**：手部形态、道具形状、动作与身体结构自洽；崩手/道具变形即打回重出。

## 与风格测试的隔离

场景图**不参与**风格可用/不可用判定（判定只认 style-test-kit 的双视图测试图），场景图的成败**不回填**风格库状态列。原因：场景图变量太多（环境、光线、动作、道具），翻车无法归因到风格本身。

## 发布提示（不限制生成，只提示发布）

- 「指间夹烟轻吐烟雾」等含烟草画面的图，在抖音等国内平台发布可能触发审核或限流；生成不受此限，发布前由用户自行斟酌。
