# 漂移诊断与修复

## 1. 先判断：随机、提示词，还是模型？
| 测试 | 做法 | 结论 |
|---|---|---|
| 多采样 | 同提示词 3–4 张 | 只偶尔错 → 随机，重抽；每张都错 → 继续排查 |
| 最小提示词 | 只留锚点块，再逐段加回 | 加某段后出错 → 该段有歧义/冲突，改写它 |
| 跨模型 | 同提示词换一个模型 | 都错 → 优先怀疑提示词（也可能是共同能力限制）；仅一个错 → 优先怀疑该模型限制（不排除歧义）——只是线索，记下平台适配差异后再定位字段 |
| 参考图核查 | 去掉参考图再试 | 去掉后正常 → 参考图分工没写清或参考图本身干扰 |

## 2. 常见症状 → 先查哪里
| 症状 | 优先处理 |
|---|---|
| 脸变了 | 锚点里脸的描述是否太泛；母版是否用了戏剧光；是否加了身份参考 |
| 两个角色融合 | 同框时逐人写锚点 + 位置；分别给参考图并声明对应 |
| 服装换了 | 服装是否逐件写清；镜头变量是否误写了服装 |
| 太像别的角色 | 剪影、比例、脸部结构、重复零件（回到设计自检） |
| 太脏/太华丽 | 碎饰、雕花、噪点、无功能首饰 |
| 数量不对 | 让可数部位可见且分离；出图后计数 |
| 风格漂移 | 风格描述是否每张逐字一致；写实度是否被改 |
| 新图总像上一个角色 | 同会话污染：提示词加隔离句（与之前图无关、不复用旧脸/发型/服装/道具）；固定角色反复出图攒出的污染换新对话；本就要延续上一版的，在提示词里明说延续哪张 |

## 3. 修还是重生成
- 局部错误、身份正确 → 局部编辑修复。
- 脸或体型错 → 不修，回母版重新派生。
- 母版本身有问题 → 在交付任何派生资产前重做母版；重做按 SKILL.md 步骤 ⑥ 的改版规则升版本处理（旧版派生资产标记待重派生、交接只交新版）。

## 4. 记录
把每次诊断结论写进锁定记录的"已知弱点"，后续提示词提前加强该部位。
