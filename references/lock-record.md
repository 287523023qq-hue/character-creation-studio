# 锁定记录模板

母版确认后立即填写。左右口径：**单侧特征一律双写——角色侧（画面侧）**，例：`痣：角色右颊（画面左侧）`。其中**角色侧是永久锁定口径**；画面侧以母版（正面）视角为基准标注、只作辅助——换视角或换面板时（尤其背面，左右与正面相反）画面侧须按当前视角重新换算，不许把母版的画面侧当跨图不变项照抄；验收以角色侧为准、画面侧按所在图视角核对。只写一侧的记录视为不合格，验收前先补齐（历史上曾因日志按画面记、本记录按角色记，两套标准混用判错）。

```
角色名 / 版本号：            母版文件：
所属世界观：                  （world-lock 文件名/世界名；无则注明「无世界观锁定」）
身份一句话：
物种与身体比例：            （头身比、身高印象、体型）
脸：                        （脸型、眼形与颜色、眉、鼻、嘴、肤色、标记）
发：                        （颜色、长度、质地、分缝、发饰位置）
服装层次与配色：            （内→外，逐件材质与颜色）
配件位置：                  （例：耳饰在角色左耳）
核心道具：                  （类型、长度、结构、挂载/握持手）
可数特征：                  （扣子×5、角×2 …）
风格描述：                  （style-library 编号 + 原句）
不可变字段：
本次允许变化：
尚未展示 / 推定区域：        （背面、被遮挡的手等，确认前不算锁定）
已知弱点：                  （模型反复画错的部位）
变更日志：                  （日期、改了哪个字段、原因）
```

规则：文字一致不等于图像一致，每张派生图都对照此表逐项检查。推定区域经用户确认后再并入不可变字段。
