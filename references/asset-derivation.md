# 派生资产规格

总原则：都以母版为参考图 + 锁定记录锚点块；**每张只改下表「只允许变化」列（白名单）内的字段**；出图后按同一份白名单对照锁定记录验收。

| 资产 | 默认规格 | 只允许变化 |
|---|---|---|
| 全身三视图 | 16:9，正面 0° / 侧面 90° / 背面 180°，同尺度 A-pose，浅灰或白底，无文字 | 观察角度 |
| 头部图（头身分离·头） | 16:9，正面 / 3/4 / 侧面同尺度；只出头＋完整颈部（裸区），不带任何服装、配饰与肩部——让脸占满像素、供视频抓面部结构与转面角度 | 观察角度 |
| 面部转面（头肩版，可选） | 16:9，正面 / 3/4 / 侧面，头肩同尺度；仅领口、肩部结构复杂的角色才出，标准集默认由头部图承担转面参考 | 观察角度 |
| 表情板 | 16:9 九宫格（平静、微笑、大笑、惊讶、疑惑、愤怒、悲伤、恐惧、厌恶），同裁切同光线；裁切与头部图一致（头＋完整颈部、不带服装）——头颈比例是验收对象，不许裁掉脖子 | 面部肌肉 |
| 分工表情板（多首/多面角色必备） | 16:9，2 行 × 3 列 6 格；每格全部头部同框，裁切光线与表情板一致；每格一个分工场景，逐首的表情与视线按锁定记录的分工表执行（交付定义见 handoff-package「分工表情板」节） | 各头部的表情与视线分配 |
| 细节板 | 道具、配饰、纹样放大 + 色板（色值） | 景别 |
| 定妆照 | 3:4，有性格的姿态与造型光，可加 1–2 个环境提示 | 姿态、光线、背景 |
| 换装 | 同脸同发同体型，只换服装层 | 服装 |

要点：
- 定妆照与母版的姿态、握持方式、武器出鞘状态就是后续一切动作的起点：选定时按"动作可推演性"验一遍——从这个姿势出发，典型动作能不能自然接上；起点错了，后续动作提示词怎么写都是圆谎（验收细则见 acceptance-checklist 定妆照节）。
- 侧/背面不是镜像复制，要延续同一结构；背面未知时用低复杂度、延续正面材质的推定设计并标注。
- 三视图默认不带武器，道具单独出细节板，避免遮挡服装。
- 表情不改变年龄、物种、五官基础。
- 定妆照可用戏剧光，但不能反过来当母版。
- 场景图（环境＋角色＋动作的成品图）不走本表白名单，单独按 `scene-derivation.md` 执行。
