# 世界观锁定

一个项目/系列共用一张的世界层定版单：先有世界，再有角色。单个角色流程默认跳过世界观，长期项目里每个角色各画各的、画风迟早散架——本文件就是补这个缺口的。

## 何时建

- 群像、系列、长期项目：**必建**，在第一个角色开工前建。
- 单角色长期使用：**建议建**（与 SKILL.md 步骤 ② 口径一致）；不建的在该角色锁定记录里注明「无世界观锁定」。
- 单角色一次性使用：可跳过，但要在该角色锁定记录里注明「无世界观锁定」——跳过是明示的选择，不是遗漏。

## 上位规则（画风以世界层为准）

- 角色的风格选择、风格组合、探索抽到的风格，都不得突破本文件的**统一画风**与**禁用元素**；风格只在世界层允许的范围内选。
- 单个角色不得私自破例。要破例：先改本文件（记变更日志、注明影响哪些已锁定角色），再改角色；顺序反了就是漂移。
- 与 SKILL.md 意图优先级的关系：用户的**当前明确要求**仍最高；用户没特别指定时，世界观锁定高于单个角色的风格偏好与 Skill 默认值。

## 模板

```
世界名 / 项目：
时代与工艺/科技水平：        （例：低魔中世纪，铁器手工业，无火药）
材料体系：                    （可用材料 / 禁用材料，如禁塑料、禁拉链）
配色底色：                    （世界主色调、饱和度与明度倾向）
统一画风：                    （style-library 编号 + Style 行；组合写明配方与各出哪层）
光影与气候基调：              （例：多雾、冷光、湿润质感）
服装与器物体系：              （形制范围、纹样来源、阶层差异怎么体现）
禁用元素：                    （绝不出现的物件、风格、材质、符号）
世界共性特征：                （所有角色共享的可见标记，如制式徽记、材质语言）
变更日志：                    （日期、改了哪项、原因、受影响角色）
```

## 与其他文件的关系

- 群像的世界共性（group-system 步骤 ②）就是本文件的简版；建了本文件，系统表直接引用，不另写一套。
- 探索模式（subject-draw）的世界共性：项目有本文件时直接引用，不另定。
- 交接包带上本文件（见 handoff-package），视频侧同样受统一画风与禁用元素约束。
