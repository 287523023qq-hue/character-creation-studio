# 验收清单（逐项打勾版）

SKILL.md 第 7 节的执行工具。**铁律：看图后才验收**；只写了提示词时只能说"完成文字检查"，本清单一张都不许打勾。

打勾方式：每项标 ✅ 通过 / ❌ 不通过 / ⚠️ 未验证（被遮挡、看不清、分辨率不够）/ ➖ 不适用（该主体或该资产没有这一项，如无发主体之于「发」、只展示道具的细节板之于「脸」——先按主体与资产类型圈定适用项，不适用不算未验证、不计入 ⚠️ 计数）。⚠️ 不能当 ✅ 用，交付时要向用户明说哪些是 ⚠️。

## A. 通用项（每张派生图都查）

（本组按「本资产白名单之外的字段不变」判读：白名单内的变化——定妆照的姿态/光线/背景、三视图默认去武器、换装的服装层——不算违反下面任何一条。白名单见 asset-derivation.md。）

- [ ] 与母版并排看，第一眼是同一个人
- [ ] 脸：脸型、眉、眼形与瞳色、鼻、嘴与锁定记录逐项对得上
- [ ] 标记：痣、疤等位置型特征在正确的一侧——按锁定记录的**双写标注**核对：**以角色侧为准**，画面侧按本图所在视角换算后核对（背面与正面左右相反，不许拿母版的画面侧硬套）；记录里只写了一侧的，先补成双写再验收
- [ ] 发：颜色、长度、质地、分缝、发饰位置不变
- [ ] 体型：头身比、肩宽、身高印象不变
- [ ] 服装：层次顺序、每件的材质与颜色、扣合方式不变
- [ ] 可数特征：实际数过——扣子、珠子、角、饰品数量与记录一致
- [ ] 道具：结构、长度、挂载/握持位置与记录一致
- [ ] 风格：渲染方式与全套资产一致，写实度没被偷换
- [ ] 本次允许变化的维度之外，没有其他维度跟着变

## B. 分资产附加项

**三视图**
- [ ] 三个角度同尺度、同一身高线
- [ ] 侧面、背面延续同一结构，不是镜像复制、不是另换一套服装
- [ ] 背面若用了推定设计，已在锁定记录标注"推定"

**头部图（头身分离·头）**
- [ ] 3/4 与侧面仍能认出是母版那张脸
- [ ] 侧面看不见的标记（如另一侧的痣）没有被硬补出来
- [ ] 只出头＋完整颈部，没有混入服装、配饰或肩部
- [ ] 头颈比例与母版一致：颈长与头高、头宽之比不变（转面只改角度，不改头颈结构）；漂移按白名单外改动打回

**表情板**
- [ ] 九格表情只动面部肌肉，年龄、五官基础、发型不变
- [ ] 头颈比例与母版并排核对：颈长与头高之比、头宽不变（A 组「头身比」在头部裁切里量不了，以本条为准）；漂移按白名单外改动打回（2026-10-23 蛙人资产包实证：表情板整板缩颈而自检放行，先生定补此条）
- [ ] 九格裁切与光线一致，裁切与头部图同口径（头＋颈、不带服装）
- [ ] （多首/多面角色）分工表情板 03b：每格各头部数量可数、位置与锁定记录命名一致；逐首抽查表情与视线对得上分工表；各头脸型回母版，不许被头部图的漂移带偏

**细节板**
- [ ] 放大部位的结构与母版一致（不是重新设计了一个）
- [ ] 色板色值与图中实际颜色对得上

**定妆照**
- [ ] 戏剧光没有改变脸的骨相与肤色认定
- [ ] 姿态符合角色性格，不是通用摆拍
- [ ] **动作可推演性**：定妆锁定的不只是外观，还是后续动作的起点——握法、武器出鞘状态、站姿重心须能顺推出该角色的典型动作链；起点锁错（例：反握持剑却要编排横斩），后面每个动作都得圆谎。判定时实际推演一遍：从当前姿态出发，角色的招牌动作能不能自然接上（源自视频线 2026-10-18 教训，先生定）

**换装**
- [ ] 只变服装层；脸、发、体型、道具挂载习惯不变

## C. 打回规则

- A 组任何一项 ❌ → 这张不交付。按 diagnosis.md 判断是编辑修复还是回母版重新派生，并把结论记进锁定记录「已知弱点」。
- ⚠️ 项（不含 ➖ 不适用）超过 2 个 → 换更高清版本或更清楚的角度重出，不许带着一堆未验证交付。
- 全部 ✅（⚠️ ≤ 2 且已向用户说明）→ 交付，在锁定记录变更日志里记一行：日期、资产名、验收结论。
