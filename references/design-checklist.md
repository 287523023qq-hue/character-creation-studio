# 反模板化设计自检

用途：在写提示词之前过一遍，发现"AI 通用脸、通用装备、通用性格"。每项给 ✅ / ⚠️ / ❌，❌ 必须先改设计。

## A. 十二维清单

| 维度 | 通过标准 | 典型失败 |
|---|---|---|
| 1 剪影 | 涂黑缩到拇指大小仍能认出；有一个独特外轮廓（帽形、发型、披挂、武器长度、体态） | 宽肩+披风+大腰带的通用英雄轮廓 |
| 2 比例 | 头身比、肩宽、腿长、重心有明确选择，且服务性格 | 所有角色同一身高同一健美体型 |
| 3 脸 | 用骨相（脸宽、颧骨、下颌、眼眶、鼻、嘴）、年龄痕迹、轻微不对称区分 | 大眼尖下巴小鼻子的统一美人/网红脸 |
| 4 发与毛发 | 发际线、长度、质地、分缝、颜色写死；有一个可识别处理 | "长黑发"之类无法锁定的描述 |
| 5 服装层次 | 内层 → 主体 → 承重/连接 → 配件，看得出怎么穿、怎么扣 | 装饰堆满但看不出衣服结构 |
| 6 材质 | 2–3 种主材质有对比（粗布/皮革/金属/骨/丝），厚薄、光泽、磨损不同 | 全身同一种塑料质感 |
| 7 色板 | 主色 60% / 辅色 30% / 强调色 10%，强调色落在视觉中心 | 每块都鲜艳，没有中心 |
| 8 道具 | 1 个核心道具能解释身份或能力；结构、握法、挂载位置明确 | 随机挂满符号，换谁都能用 |
| 9 不对称与记忆点 | 至少 1 个不对称元素（单肩甲、一侧耳饰、伤疤、断角）+ 1 个"一句话就能描述"的记忆点 | 完全对称、无可复述特征 |
| 10 磨损与痕迹 | 痕迹出现在接触与受力处，有故事来源 | 全身均匀泥锈破布 |
| 11 世界观契合 | 材料、工艺、科技程度、文化语汇与世界设定一致；跨文化混搭有明确意图 | 西方角色随手加佛珠，东方角色套骑士脸 |
| 12 姿态与行为 | 站姿、重心、手势、视线体现性格 | 全员正面直立同角度持武器 |

## B. 三重复检查（群像必做）
- **同轮廓**：剪影是否撞型？
- **同零件**：腰带、护肩、披风、刺饰是否在多人身上重复？
- **同性格**：表情与姿态是否同一种"酷"？
两人之间至少在三个维度上可见不同；仅换主色不算区分。

## C. 抽象词翻译表
| 用户说 | 翻译成可见设计 |
|---|---|
| 高级 | 收紧色板、减少碎饰、提升材质对比与剪裁精度 |
| 神秘 | 遮挡局部（兜帽、面纱、阴影中的眼）、低饱和、少量异常细节 |
| 霸气 | 加大体量与重心、低机位感的站姿、厚重材质 |
| 可爱 | 圆形主轮廓、头身比降低、大面积纯色 |
| 赛博 | 指定部位的功能性改造（眼、手臂、接口），说明连接方式 |

## D. 细节密度
细节集中在脸、核心道具和 1–2 个识别区；其余留"安静面"。"太华丽"先减重复雕花与无功能首饰；"太素"先加强比例、材质对比或核心道具，而不是全身加装饰。"干净"=去噪点与碎饰，不是去材质。

## E. 物种完整性
非人类角色的头、颈、躯干、四肢、手足、毛发属于同一套解剖逻辑；写实不等于人类化，避免"人戴动物面具"。
